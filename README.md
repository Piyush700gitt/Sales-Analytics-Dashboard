# Sales Analytics Dashboard

An interactive Sales Analytics Dashboard developed using
Python, Streamlit, Pandas and Plotly.

## Features

- CSV, Excel and JSON upload
- Data validation
- Missing value handling
- Duplicate removal
- Data preprocessing
- Interactive filters
- Five dynamic KPIs
- Interactive visualizations
- Statistical analysis
- Cleaned data download

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Openpyxl

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
